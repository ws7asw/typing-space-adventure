# 🚀 打字太空冒險 Typing Space Adventure

適合小朋友的**中英雙語打字練習遊戲**。單字從天而降，打對即可消除並保護太空船。可在手機、平板、電腦遊玩，也能加到 iOS／Android 主畫面（PWA）。

## ✨ 特色

- **分年級單字表**：一～六年級主題式單字（依教育部英語課綱精神＋翰林常見進度整理）
- **句子練習**：難度越高越容易出現較長英文句子（含空白鍵）
- **10 級難度滑桿**：左右拖拉調整速度與句子比例
- **火箭自動對準**：尖端朝上，自動移到最近目標下方
- **飛彈升級**：答對次數越多，飛彈威力越強（穿透／扇形／濺射）
- **中英雙語**：每個單字／句子顯示中文意思，邊玩邊背
- **管理單字表**：手動新增、批次匯入、匯出 JSON、刪除自訂字
- **自動翻譯**：輸入英文可自動抓中文（MyMemory API；需網路）
- **觸控發射按鈕**與虛擬鍵盤（含空白鍵）
- **排行榜 Top 10**：結束後可輸入姓名登錄成績（存於本機瀏覽器）
- **完全離線可玩**（自動翻譯除外）：純 HTML／CSS／JS，無套件

## 🎮 玩法

1. 選擇年級單字表（或全部混合／自訂單字）與速度
2. 按「開始遊戲」
3. 打出掉落單字的字母；打完整個單字即加分
4. 單字掉到底部扣一顆 ❤️；三顆用完結束
5. 每消 10 個字進入下一關，速度加快

- 電腦：實體鍵盤  
- 手機／平板：畫面下方虛擬鍵盤（金色＝下一個鍵）  
- `Esc` 或 ⏸：暫停

## 📝 單字表怎麼用

### 內建分年級表

| 年級 | 約略字數 | 主題方向（參考） |
|------|----------|------------------|
| 一年級 | 54 | 顏色、數字 1–10、打招呼、教室、常見小物 |
| 二年級 | 60 | 數字 11–20、家人、身體、心情、動物／食物入門 |
| 三年級 | 74 | 動物、文具、水果、衣物、形容詞、動詞（Dino 1–2） |
| 四年級 | 84 | 整十數、動作、房間、位置、食物、時間（Dino 3–4） |
| 五年級 | 86 | 職業、能力、地點、天氣、星期、月份、節慶（Dino 5–6） |
| 六年級 | 82 | 方位、過去式、興趣、情緒、科目、交通（Dino 7–8） |
| **合計** | **約 440** | 跨年級去重後約 435 個不同英文單字 |

說明：教育部課綱提供**參考字彙**，並未規定「某年級必背固定清單」。本表為教學進度參考，可於遊戲內自行增修。

### 手動新增

1. 點「📝 管理單字表」
2. 選年級（或「自訂單字」）
3. 輸入英文＋中文 →「＋ 新增」  
   - 中文可留空，點「🌐 翻譯」自動抓取

### 批次匯入

在管理畫面展開「📥 批次匯入」，每行一個：

```text
apple,蘋果
banana,香蕉
tiger
```

或貼上 JSON：

```json
[
  { "en": "apple", "zh": "蘋果" },
  { "en": "banana", "zh": "香蕉" }
]
```

勾選「自動翻譯」時，沒有中文的單字會自動補上。自訂字存在瀏覽器 `localStorage`，同一裝置會保留。

### 匯出

「📤 匯出此表」會下載該年級（內建＋自訂）的 JSON。

## 🕹️ 如何執行

```bash
# 在專案資料夾
python3 -m http.server 8765
```

瀏覽器開啟：`http://localhost:8765`

（直接雙擊 `index.html` 通常也能玩；自動翻譯需透過本機伺服器且可連網。）

## 📱 加到 iPhone / iPad 主畫面

1. 用 Safari 開啟遊戲網址  
2. 分享 → **加入主畫面**  
3. 從主畫面圖示開啟即為全螢幕體驗

## 📁 檔案結構

| 檔案 | 說明 |
|------|------|
| `index.html` | 畫面結構（開始／遊戲／管理單字表） |
| `style.css` | 太空主題響應式樣式 |
| `game.js` | 遊戲邏輯、單字管理、自動翻譯 |
| `words.js` | 分年級內建單字庫 |
| `manifest.json` | PWA 設定 |
| `icon.svg` | App 圖示 |

## 🔧 想直接改內建單字？

編輯 `words.js` 對應年級的 `themes[].words`：

```js
{ en: "planet", zh: "行星" }
```
